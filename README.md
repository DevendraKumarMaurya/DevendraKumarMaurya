## 🚀 Featured Projects

### 🧠 [ThreadPoint](https://github.com/DevendraKumarMaurya/ThreadPoint)
> **Engineering-Focused Technical Q&A and Knowledge Exchange Platform**  
> `React 19` • `Vite` • `Tailwind CSS` • `Node.js` • `Express.js` • `PostgreSQL`

- **Community Knowledge Sharing**: Built a developer-focused platform for asking questions, posting answers, voting, bookmarking, commenting, following users, and discovering topics.
- **Database-Enforced Invariants**: Designed PostgreSQL triggers, stored procedures, partial unique indexes, and full-text search to enforce accepted-answer integrity, reputation scoring, and ranked question discovery.
- **Authentication**: Implemented Google OAuth, local email/password authentication, OTP verification, and account linking with secure session flows.
- **Resilient Architecture**: Added an in-memory fallback store with seeded demo data for development and offline evaluation when PostgreSQL is unavailable.
- 🔗 **Repo**: [github.com/DevendraKumarMaurya/ThreadPoint](https://github.com/DevendraKumarMaurya/ThreadPoint)

- **Assessment Management**: Implemented end-to-end exam scheduling, question bank repository creation, and role-based access control.
- **Analytics & Publishing**: Built evaluation engines that produce instant result-publishing workflows accompanied by granular, question-wise student performance breakdowns.
- **Deployment**: Configured and deployed production builds using Firebase Hosting with low-latency Firestore database sync.
